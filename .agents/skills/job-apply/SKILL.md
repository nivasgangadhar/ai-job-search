# Applications in Codex

Read the repository-root `AGENTS.md` and `CLAUDE.md`, then
[Codex compatibility](../../../docs/CODEX_COMPATIBILITY.md). For a full
application follow the canonical [apply workflow](../../../.claude/commands/apply.md).
For evaluation only, a single document, or form fields, use the task routing in
[the application skill](../../../.claude/skills/job-application-assistant/SKILL.md)
and read only the needed methodology references there.

Gate postings before evaluation, ground facts in the three canonical sources,
and present fit before drafting. An unconfigured profile requires setup before
personalized evaluation. Perform fetch and review as separate sequential stages
as the compatibility guide specifies. Preserve compilation, visual inspection,
ATS checks, tracker recording as `drafted`, and posting archival for full
applications. Drafting does not submit an application or authorize outreach.
